==========================================================
 用 Git 推送网站更新 · 简明教程
==========================================================

【这是什么】
你的网站源码在本地文件夹 F:\MyPage，托管在 GitHub Pages，
线上地址是 https://naalh4.github.io/ 。

本地改完文件后，需要把这些改动"上传"到 GitHub，网站才会更新。
这个"上传"动作，就是 git push（推送）。


----------------------------------------------------------
 一、前期准备（只需做一次）
----------------------------------------------------------

1. 确认电脑装了 Git（Git Bash 终端里输入 git --version 有输出即可）。

2. 配置身份（第一次提交前配一次，以后不用重复）：
   git config --global user.name "NaAlH4"
   git config --global user.email "你的邮箱@xxx.com"


----------------------------------------------------------
 二、每次更新的标准流程（四步）
----------------------------------------------------------

打开终端（Git Bash），依次执行下面命令：

第 1 步：进入项目目录
   cd /f/MyPage

第 2 步：查看改了哪些文件（可选，用于确认）
   git status

第 3 步：暂存所有改动
   git add -A

第 4 步：提交，并写一句这次改了什么
   git commit -m "描述这次改动"

第 5 步：推送到 GitHub
   git push

看到类似 "Writing objects ... done" 就说明推送成功，
几分钟后刷新 https://naalh4.github.io/ 就能看到更新。


----------------------------------------------------------
 三、复制即用的模板（最常用）
----------------------------------------------------------

   cd /f/MyPage
   git add -A
   git commit -m "更新说明"
   git push

把这四行记下来，以后每次改完网站跑一遍即可。


----------------------------------------------------------
 四、常见问题
----------------------------------------------------------

【4.1】push 时报 "Connection was reset"（连不上 GitHub）
  这是网络问题，不是代码问题，改动都还在本地、不会丢。

  解决：先开代理 / VPN，再重试：
     git push

  如果开了代理还是不行，把代理端口配给 git（7890 是
  Clash / V2ray 的常见默认端口，按你的实际端口改）：
     git config --global http.proxy http://127.0.0.1:7890
     git config --global https.proxy http://127.0.0.1:7890
     git push

  想取消代理配置时：
     git config --global --unset http.proxy
     git config --global --unset https.proxy

【4.2】commit 时报 "Please tell me who you are"
  说明没配身份，执行：
     git config --global user.name "你的名字"
     git config --global user.email "你的邮箱"
  然后重新 git commit。

【4.3】想撤销刚才的 commit（还没 push 时）
     git reset --soft HEAD~1
  改动会回到"已暂存"状态，文件本身不会丢。


----------------------------------------------------------
 五、常用命令速查表
----------------------------------------------------------

  git status              查看当前状态（哪些文件改了/新增了）
  git add -A              暂存所有改动
  git add 文件名          只暂存某个文件
  git commit -m "说明"    提交（-m 后面是说明文字）
  git push                推送到 GitHub
  git pull                拉取 GitHub 上的更新到本地
  git log                 查看提交历史
  git diff                查看具体改了什么内容
  git remote -v           查看远程仓库地址


----------------------------------------------------------
 小提示
----------------------------------------------------------

· 每次改动写一句清楚的 commit 说明，以后好找。
· push 之前先 git status 看一眼，避免把不想传的文件也传上去。
· 图片、图标这些文件也要一起 add + commit，否则网站上会缺图。
